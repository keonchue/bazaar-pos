# 바자회 POS (2026-11-08)

서적부 POS 를 바탕으로, 사업팀 POS 의 예약(선주문) 기능을 붙여 바자회용으로 다시 짠 웹 포스기입니다.
여러 기기가 실시간으로 같이 쓰고, 모든 판매가 **구글 스프레드시트에 자동으로** 적힙니다.

## 기능
- 개업 / 마감 (마감 때 현금 · 계좌이체 합계, 안 가져간 예약, 시트 대조 결과를 같이 보여 줌)
- 판매: 계좌이체 · 현금 · 분할결제, 할인(원 / %) + 할인 사유, 0원 출고(시식 등)
- 반품: 부분 반품, 분할 건은 현금 · 이체 환불액 따로, "다시 팔 수 있음" 끄면 폐기 처리
- **예약**: 성함 · 연락처 · 상품 · 입금 여부 → 수령 처리 때 매출로 잡힘. 예약분은 현장 판매에서 자동으로 빠짐
- 재고: 입고 · 재고 수정(실사) · 가격/분류 · 변동 이력
- 매출 내역 · 리포트(이번 영업 / 오늘 / 전체 / 기간) · CSV · JSON 백업/복원 · 전체 초기화
- PWA (홈 화면 설치 · 오프라인 실행)

## 처음 상품
| 상품 | 분류 | 예상 수량 |
|---|---|---|
| 딸기 요거트 | 딸기 | 12 |
| 딸기 녹차초코 | 딸기 | 11 |
| 바나나 다크초코 | 바나나 | 12 |
| 바나나 녹차초코 | 바나나 | 12 |
| 귤 요거트 | 귤 | 11 |
| 귤 화이트초코 | 귤 | 12 |

- **가격은 0원(미정)** 으로 들어갑니다. 0원 상품은 판매 · 예약이 막히니, 정해지면 📦 재고 → `정보` 에서 넣으세요.
- 예상 수량은 시트에 `입고` 로 남습니다. 실제 만든 수량이 다르면 `재고 수정` → 시트에 `재고조정` 줄이 갑니다.
- **녹차 음료**는 정해지면 `＋ 새 상품 등록` (분류: 음료).
- 상품 기본값은 `index.html` 의 `SEED_PRODUCTS`.

## 구글 시트
새 스프레드시트에 `apps-script/Code.gs` 를 붙이고 `시트_만들기` 를 실행하면 이 탭들이 생깁니다 (설치 순서는 Code.gs 맨 위).

| 탭 | 내용 |
|---|---|
| `판매기록` | 원장. 판매 · 반품 · 입고 · 재고조정이 **상품 한 줄씩** |
| `요약` | 수식만. 순매출 · 현금 · 계좌이체 · 할인 · 반품 · 예약 현황 · 상품별 표(입고 / 판매 / 반품 / 남은 재고 / 매출) |
| `예약` | 예약 한 건 = 한 줄. 입금 · 수령이 바뀌면 그 줄이 그 자리에서 바뀜 |

`판매기록` 의 모든 줄은 언제나 이 식을 지킵니다:
`금액 = 단가 × 수량 − 할인`, `현금 + 계좌이체 = 금액`, 반품은 음수 → 열을 그냥 SUM 하면 순매출.
할인 · 분할결제는 정수 원 단위로 품목에 나눠서 **합이 1원도 어긋나지 않습니다.**

### 오류가 없게 하는 장치
1. 줄은 `ledger.js` 한 곳에서만 만들고, 저장 직전에 식을 다시 검사합니다. 어긋나면 결제를 저장하지 않습니다.
2. 못 보낸 기록은 Firestore `sheetQueue` 에 쌓이고 켜진 기기 아무 데서나 보냅니다 (인터넷이 끊겨도 잃지 않음).
3. 같은 기록을 두 번 보내도 시트는 한 번만 적습니다 (`_전송기록`). 시트가 거절하면 반쪽 줄을 지우고 이유를 보여 줍니다.
4. **🔍 시트 대조** (⚙ 설정, 마감 화면, 10분마다 자동): 앱 기록과 시트를 한 칸씩 비교해서
   `✓ 시트와 앱이 완전히 같습니다` 또는 다른 곳 목록을 보여 줍니다. **🛠 고치기** 는 앱 기록대로 시트를 맞춥니다.
5. 헤더에 `⚠ 시트 …` 칩이 뜨면 문제가 있다는 뜻입니다 (미연결 · 옛 스크립트 · 대기 · 거절 · 불일치).

⚠ `판매기록` · `예약` 탭은 손으로 고치지 마세요. 고치면 대조가 찾아내고, 고치기를 누르면 앱 기록으로 되돌아갑니다.

## 시험
```
node tests/run.mjs          # 돈 나누기 · 줄 만들기 (무작위 수천 건) + Code.gs 를 시트 흉내에 돌려 보기
node tests/e2e-server.mjs   # http://localhost:5199 — 가짜 Firebase + 시트 흉내로 화면 전체를 써 보기
```
`Code.gs` 를 고치면 `ledger.js` 의 `MIRROR_VERSION` 과 `Code.gs` 의 `MIRROR_VERSION` 을 같이 올리고,
Apps Script 에서 **배포 관리 → ✏️ → 새 버전** 으로 다시 배포합니다 (앱이 버전이 다르면 경고합니다).

## 배포 순서
1. `SETUP-firebase.md` 대로 Firebase 프로젝트 → `firebase-config.js` 채우기 → `firestore.rules` 게시
2. 정적 호스팅(GitHub Pages 등)에 올리기
3. 새 스프레드시트 + `Code.gs` → 앱 ⚙ 설정 → 🔗 시트 연동
4. 시험 판매 몇 건 → 🔍 시트 대조 확인 → ⚙ 설정 → 🧨 전체 초기화 (앱과 시트의 시험 기록이 같이 지워짐)
5. 가격 입력 → 11월 8일 개업
